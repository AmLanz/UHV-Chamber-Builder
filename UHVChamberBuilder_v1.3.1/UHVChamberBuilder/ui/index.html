Quick start

  1. Build asks before switching the current design to Hybrid. Start with Load example → Preview all → Build / update all.
  2. Edit points, body shapes and flanges. The + beside each row reveals its extra settings.
  3. Save the Fusion document. Export a recipe ZIP for a portable copy with tables and selected-solid snapshots.

Coordinates

For flanges and body shapes, azimuth is the angle from +X; a negative value selects the opposite Y half. Elevation rotates the complete frame about X, positive toward +Z on either half. Thus 0°/0° points along +X, 90°/0° along +Y, and 90°/90° along +Z. Azimuth 0° remains along +X at every elevation. Keep the reference point, face distance, absolute azimuth and roll identical for a symmetric ring. Tube-end flanges follow their tube; roll rotates the bolt pattern around the outward axis.

Connections and updates

Shapes and necks become one Main chamber; each flange is a component. Automatic necks can connect to other port necks regardless of row order. For an ambiguous connection, select its target or enter a manual neck length. Existing solids require manual lengths.

A row Build includes base shapes, previously built flanges and required parent necks. Build / update all applies everything, including removals. Clear preview restores the built chamber and removes recognized UHV preview leftovers from earlier runs. Previews are also cleared before saving. For sections, clear preview and use Fusion’s Inspect → Section Analysis.

Flange numbers

Numbers start blank. Enter a unique positive whole number before Build; gaps are allowed. ↑ / ↓ change table order. Copy inserts below the source with an empty number. Sort by flange number puts unnumbered rows last, ordered by component name. Sorting never renumbers.

Defaults and details

Shared dimensions and the light/dark switch are on Defaults. Deviate unlocks per-row values. Selecting a different standard size resets those overrides. Seal details, rotatable retaining geometry and fasteners are schematic; tool envelopes use your supplied dimensions.

Gaskets

The offset runs from the outer flange face to the outer gasket face. The gasket extends one thickness inward from that plane. Zero is flush; negative offsets place the outer face inside the flange. Overlap is allowed: each gasket stays in a separate component under its flange.

Keep your work

Rebuilds can replace faces and edges. Put manual finishing features in a separate copy. Export an unbuilt draft before starting another. Errors include a diagnostic-log path.
